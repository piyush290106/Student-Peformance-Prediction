# 🌟 STUDENT PERFORMANCE PREDICTION SYSTEM 🌟

## 🔹 PROBLEM STATEMENT

Educational institutions face difficulty in identifying whether a student will **PASS or FAIL before final examinations**.

Teachers and administrators require a system that can **analyze student background details** and estimate academic performance in advance.

This project develops a **Web-Based Student Performance Prediction System**.

---

## 📌 USER INPUTS

✔ **Gender**
✔ **Race / Ethnicity**
✔ **Parental Education Level**
✔ **Lunch Type**
✔ **Test Preparation Course**

---

## 📊 SYSTEM PREDICTIONS

✔ **Math Score**
✔ **Reading Score**
✔ **Writing Score**

---

## ⚙ KEY FEATURES

✔ Predict student academic performance

✔ Determine **Pass / Fail Status** based on predicted scores

✔ Calculate and display **Overall Average Score**

✔ Generate **Graphs and Charts** for performance analysis

✔ Provide a **Data Analysis Dashboard** for visualization

---

## 📏 PASSING CRITERIA

✔ **Passing Threshold = 65 Marks**

---

## 🎯 PROJECT OBJECTIVE

✔ Help teachers and institutions identify student performance early

✔ Support better academic planning and decision-making

✔ Improve monitoring of student progress through data analysis
