# SDLC (Software Development Life Cycle)

## 1. Planning Phase

### 🎯 Objective:

✔ Develop a web application to predict student performance.

### 📌 Scope:

✔ Predict Math, Reading, and Writing scores
✔ Display Pass/Fail result
✔ Show overall average score
✔ Provide dashboard with graphs and analysis

### 🛠 Tools:

✔ Python
